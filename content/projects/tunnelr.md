## Overview

TunnelR is a cross-platform application that enables VPN-agnostic split tunneling, allowing users to route specific applications or domains through different network interfaces while maintaining seamless connectivity.

## Features

- **VPN-agnostic**: Works with any VPN provider or connection type
- **Application-based routing**: Route specific apps through VPN or direct connection
- **Domain-based filtering**: Configure rules based on domain names or IP ranges
- **Cross-platform support**: Available for Windows, macOS, and Linux
- **Easy configuration**: Simple GUI for managing tunneling rules
- **Real-time monitoring**: View active connections and routing status

## Getting Started

1. Download the latest release for your platform
2. Install and run TunnelR
3. Configure your VPN connection
4. Add applications or domains to tunnel rules
5. Enable split tunneling

## Use Cases

- **Gaming**: Route games through direct connection while keeping other traffic on VPN
- **Streaming**: Access geo-restricted content while maintaining privacy for other activities
- **Development**: Route development tools through VPN while keeping general browsing direct
- **Corporate**: Separate work and personal traffic flows
